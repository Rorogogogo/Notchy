# Notchy v1.6.1

## Fixes the icon never appearing

v1.6.0 moved Notchy into the menu bar, which exposed a macOS behaviour that made
the app look dead on a busy Mac: when the menu bar's right-hand strip is full,
macOS accepts the status item and then parks it left of the notch, where it is
never drawn. The item exists, keeps updating, and answers Accessibility queries —
it is simply invisible, with no error and no callback to react to.

Notched MacBooks have the least menu bar room of any Mac and are exactly Notchy's
audience, so this was easy to hit on a first install.

- Notchy now checks, shortly after launch, whether its icon landed inside the
  strip macOS actually draws, and books itself a real slot if it did not.
- macOS also reserves a margin beside the notch that it refuses to draw into, so
  the slot is chosen as a fraction of screen width, with a second, more
  conservative try if the first still misses.
- If no slot can be had at all, Notchy now says so once, instead of running
  invisibly forever. Quitting or hiding one other menu bar icon frees it up.

## The dark panel is back

- The status panel is drawn as a borderless black slab again, like the old notch
  pill, rather than a system popover. v1.6.0's popover was translucent, let the
  desktop bleed through the usage readings, and traced its corners with a grey
  hairline and a pointer arrow.
- Clicking the icon toggles it, clicking anywhere else dismisses it, and the
  buttons inside it work on the first click.

## Install

Download `Notchy.pkg`, open it, approve it once in Privacy & Security if prompted, and restart active agent sessions so their hooks reload.
