# Notchy v1.6.2

## Usage readings sit beside their bars

- The percentage and countdown moved down onto the bar's line. The segments are
  a fixed width, so they had been leaving a wide empty gap while the numbers
  crowded onto the label line above.
- Each window's label now gets its own line, and the reading lines up with the
  bar it describes. Row height is unchanged.

## Install

Download `Notchy.pkg`, open it, approve it once in Privacy & Security if prompted, and restart active agent sessions so their hooks reload.
