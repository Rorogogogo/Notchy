# Notchy v1.5.0

## Dynamic Codex quota windows

- Shows the quota windows Codex currently returns instead of assuming fixed 5-hour and weekly limits.
- Displays remaining allowance and exact local reset times.

## Codex reset credits

- Shows available manual reset credits and the nearest expiry.
- Remains read-only; credits are consumed through Codex `/usage`.

## Reliability and polish

- Falls back to recent local session data when the Codex app-server is unavailable.
- Respects manual Notchy quits.
- Includes the redesigned Notchy icon and refreshed documentation.

## Install

Download `Notchy.pkg`, open it, approve it once in Privacy & Security if prompted, and restart active agent sessions so their hooks reload.
