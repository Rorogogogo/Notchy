# Notchy v1.6.3

## Your own statusline is no longer displaced

Installing Notchy could leave Claude Code with a blank statusline.

The installer is meant to *add* its rate-limits writer to whatever statusline
script you already have, and only fall back to its own minimal script when you
have none. But it had no way to recognise its own script. Once the fallback was
in place, every later install saw `~/.claude/notchy/statusline.sh`, treated it
as "the user's statusline", and appended to that instead — so the real one
stayed stranded and the bar stayed empty.

- The installer now recognises its own minimal script and never mistakes it for
  one of yours.
- Whatever statusline it finds is recorded in
  `~/.claude/notchy/displaced-statusline.json`.
- If it finds its own fallback in place and has a statusline recorded, it puts
  yours back and re-adds the writer block to it.

Upgrading is enough to restore a statusline stranded by an earlier version. If
you have already pointed `statusLine` back at your own script by hand, this
install leaves it alone.

## Install

Download `Notchy.pkg`, open it, approve it once in Privacy & Security if prompted, and restart active agent sessions so their hooks reload.
