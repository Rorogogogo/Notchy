# Notchy v1.5.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish and publish Notchy v1.5.0 with dynamic Codex quota windows/reset credits, refreshed README documentation, clear release notes, and a verified downloadable `Notchy.pkg`.

**Architecture:** Complete and verify the existing dirty dynamic-usage implementation before touching release metadata. Keep the current local `build.sh` packaging flow, make `1.5.0` the single bundle/package version, store the GitHub release body in the repository, then tag the exact verified commit and upload its package as the stable `Notchy.pkg` asset.

**Tech Stack:** Swift/SwiftUI/AppKit, Bash, Codex app-server JSON-RPC, `swiftc`, `pkgbuild`, `codesign`, GitHub CLI.
